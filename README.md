# NEU Surface Defect Detection

## Project Overview
This project detects surface defects in steel using Deep Learning and Transfer Learning.

## Technologies Used
- Python
- TensorFlow
- Keras
- CNN
- ResNet50
- Streamlit
- NumPy
- Matplotlib

## Dataset
NEU Surface Defect Dataset containing six defect classes.

## Model
ResNet50 Transfer Learning with Fine-Tuning.

## Model Accuracy
Validation Accuracy: 97.50%

## Application
A Streamlit web application is developed to upload steel surface images and predict defects.

## Defect Classes
1. Crazing
2. Inclusion
3. Patches
4. Pitted Surface
5. Rolled-in Scale
6. Scratches

Model Files

The trained model files are not uploaded to this repository because of their large file sizes. The models were trained and tested successfully during project development.

Project Status

Successfully completed an end-to-end Deep Learning project using CNN and ResNet50 Transfer Learning, with a Streamlit web application for steel surface defect detection.
